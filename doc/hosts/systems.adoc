= Host systems known to work

Each row says how it was checked. To add a system, or report one that
does not work, open a host report on GitHub.

== On real hosts

[cols="2,1,2",options="header"]
|===
| Host system | Protocol | Notes

== In the session test

The session test runs each kind of session against a stand-in host in
the same container, on every change; `tools/ci.sh sessions` runs it.

[cols="2,1",options="header"]
|===
| Stand-in host | Protocol

| Debian's OpenSSH | SSH / X11 (over IPv4 and IPv6), SSH terminal, key login
| Debian's xdm | XDMCP, Find Hosts
| A telnet stand-in | Telnet
| pixterm's own rexec and rsh test servers | rexec, rsh
| TigerVNC's Xvnc | VNC
| FreeRDP's shadow server | RDP
| A pseudo-terminal | Serial console
| Hosts that answer and hang up | TN3270, TN5250, Plan 9 (drawterm): the program starts and the session ends cleanly; no real mainframe, IBM i or Plan 9 yet
|===
