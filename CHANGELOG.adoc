= Changes

Each release has a section here. The release workflow copies the
section into the release notes.

== 0.10.0

The second test release: most of what 1.0 adds. Logins with hardware
security keys and Kerberos are still to come.

=== Fixed

* A session program that ended at once was not reported as an error on
a terminal: pixtermd never noted when the session's programs started.
* systemd-resolved answered LLMNR queries from the network, on port
5355. It now only looks names up, as release images promise.

=== Added

* 8-bit PseudoColor displays: an SSH or XDMCP host may ask for an 8-bit
display with a colour map, for old programs that need one. The session
runs in Xephyr, filling the screen.
* A user guide, `doc/guide.adoc`: first steps, each Configure panel,
recovery, and faults by symptom; and pictures in the README, which
`tools/screenshots.sh` takes again when the look changes.
* Each image is checked as it is built for network services: only
units on a short list may be enabled, and a release image has no SSH
server.

* IBM mainframes: TN3270E sessions in x3270, with the PC 3270 keys, in
the largest 3270 font that fits the screen. Port 992 uses TLS.
* IPv6 host addresses work with every kind of host: VNC, RDP, TN3270
and TN5250 now put them in brackets before the port. The session test
logs in to an SSH host at ::1.
* Keyboards: Sun Type 6 and Type 7 USB keyboards (Configure >
Keyboard), with Sun's extra keys for Solaris and CDE; and the DEC VT220
editing keys and PF1 to PF4 for terminal hosts that ask for them, as
OpenVMS expects.
* Configure > Time: the time zone, and NTP servers for networks with
no way to the internet. The terminal has no clock battery, and secure
connections need the right time.
* Configure > Diagnostics > Save to USB: the journal, Xorg's log and
the settings (without the PIN), for a bug report.
* Issue forms for bug reports and host reports, and a table of the
host systems known to work.
* A window manager on the terminal for SSH hosts that send none:
Configure > Hosts > Windows.
* A console during sessions, on Ctrl+Alt+Home: lock the screen with a
code chosen then, or disconnect.
* Wake-on-LAN: a host with a MAC address in its entry is woken first,
and given two minutes to answer.
* The 3270 fonts, and notes on the DEC fonts the terminal has for
DECwindows and how to reach the rest through a font server.
* Indirect GLX: OpenGL programs on IRIX, Solaris and other hosts draw
on the terminal, in software.
* Plan 9 and 9front: drawterm sessions, with 9front's drawterm (dp9ik
logins), built from a pinned commit.
* IBM i: TN5250E sessions in tn5250, built from a pinned upstream
release, with the PC 5250 keys. Port 992 uses TLS. Releases carry the
source of what the image builds from upstream.
* RDP host certificates are kept on the settings partition, like SSH
host keys, so a changed certificate is refused after a restart too.
* Configure > Hosts > Forget Host Key, for a host whose SSH key or RDP
certificate changed for a known reason. A factory reset was the only
way before.
* Wi-Fi: Configure > Wi-Fi scans for networks and joins a WPA2- or
WPA3-Personal one, hidden ones too, with DHCP. The passphrase is kept
for root alone and left out of exports.
* A blanking time in Configure > Display: the screen blanks, and the
monitor sleeps, after 5 to 60 minutes idle, or never. It used to be
fixed at 10 minutes, which stays the default.
* A text screen when the X server fails to start three times in a
row: it shows Xorg's errors, and offers to try again or to restore the
factory settings (after the administrator PIN, if one is set). The
screen used to stay blank.
* Large fonts on 4K screens, in the chooser, its dialogs, the window
frames and terminal sessions.
* A monitor plugged in at the chooser lights up, also after a start
with no monitor. It used to stay dark until the next session ended.
* XDMCP displays start at the display size chosen in Configure. They
used to start at the monitor's preferred size.
* Release files carry a signed record of the GitHub workflow and commit
that built them. `gh attestation verify` checks it.

== 0.9.0

The first public test release. It does all the old C version did,
rebuilt in C++23.

=== Added

* Sessions over SSH with X11 forwarding: `~/.xsession`, one xterm, a
command through `/bin/sh`, or a raw command for OpenVMS.
* XDMCP sessions, direct or through the host's chooser, and Find Hosts
to search the network for display managers.
* Terminal sessions over SSH and Telnet, and serial consoles.
* Direct X sessions, and commands started with rexec and rsh.
* VNC and RDP desktops.
* Login with the terminal's own SSH key.
* Configure: hosts, display mode with a timed confirmation, network,
keyboard, USB export and import, diagnostics, and an administrator PIN.
* A read-only image for the Raspberry Pi, with settings saved as
checked generations on a partition of their own.
